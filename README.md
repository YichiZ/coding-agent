# coding-agent

## Description

A small coding agent built from scratch on the Anthropic API, written to learn how coding agents work.

## Progress

- [x] One message, print the reply
- [x] Agent loop with a turn limit
- [x] Tools: bash, read, edit, list
- [ ] Handle tool errors and print the final answer
- [ ] Run tools in a Docker sandbox
- [ ] Make it a CLI
